# 03 태그




# 01 HTML 태그란?

HTML 태그는 웹 페이지의 내용과 구조를 나타내는 문법임

```html
<h1>닭발 맛집</h1>
```

`<h1>`은 시작 태그이고, `</h1>`은 종료 태그임

```html
<시작 태그>내용</종료 태그>
```

태그에 따라 제목, 문단, 이미지, 링크 등을 표시할 수 있음






# 02 제목

`<h1>`부터 `<h6>`까지 사용해 제목을 작성함

```html
<h1>가장 큰 제목</h1>
<h2>두 번째 제목</h2>
<h3>세 번째 제목</h3>
```

숫자가 작을수록 중요도가 높음

- `<h1>`: 가장 중요한 제목
- `<h2>`: 큰 단락 제목
- `<h3>` ~ `<h6>`: 하위 제목






# 03 문단

`<p>`로 문단을 작성함

```html
<p>매운 닭발을 주문하세요.</p>
```

제목보다 작은 일반적인 글자를 표시할 때 사용함






# 04 줄바꿈과 구분선

## 줄바꿈

`<br>`로 줄을 바꿀 수 있음

```html
<p>닭발이 매워요.<br>하지만 맛있어요.</p>
```

## 구분선

`<hr>`로 콘텐츠 사이에 구분선을 표시함

```html
<hr>
```

`<br>`과 `<hr>`은 종료 태그가 없는 태그임






# 05 `<div>`와 `<span>`

## `<div>`

`<div>`는 한 줄 전체를 차지하는 블록 요소임

```html
<div>하치와레 불쌍해</div>
<div>우사기 돼지</div>
```

```text
하치와레 불쌍해
우사기 돼지
```

## `<span>`

`<span>`은 콘텐츠 영역만 차지하는 인라인 요소임

```html
<span>하치와레 불쌍해</span>
<span>우사기 돼지</span>
```

```text
하치와레 불쌍해 우사기 돼지
```

특정 단어나 글자만 꾸밀 때 사용함

```html
<p>
    닭발은 <span>매운맛</span>이 맛있어요.
</p>
```






# 06 링크

`<a>`로 다른 페이지나 사이트로 이동하는 링크를 작성함

```html
<a href="https://www.google.com">
    구글로 이동
</a>
```

`href`에는 이동할 주소를 작성함

새 탭에서 열려면 `target`을 사용함

```html
<a
    href="https://www.google.com"
    target="_blank"
>
    구글 새 탭에서 열기
</a>
```






# 07 이미지

`<img>`로 이미지를 표시함

```html
<img
    src="chicken-feet.jpg"
    alt="닭발 사진"
>
```

| 속성 | 설명 |
|---|---|
| `src` | 이미지 파일의 경로 |
| `alt` | 이미지 설명 |

`alt`는 이미지가 표시되지 않거나 스크린 리더를 사용할 때 필요함

```html
<img
    src="chicken-feet.jpg"
    alt="매운 닭발 사진"
    width="300"
>
```

`<img>`는 종료 태그가 없는 태그임






# 08 목록

## 순서가 없는 목록

`<ul>`과 `<li>`를 사용함

```html
<ul>
    <li>무뼈 닭발</li>
    <li>주먹밥</li>
    <li>계란찜</li>
</ul>
```

```text
• 무뼈 닭발
• 주먹밥
• 계란찜
```

## 순서가 있는 목록

`<ol>`과 `<li>`를 사용함

```html
<ol>
    <li>메뉴 고르기</li>
    <li>맵기 선택하기</li>
    <li>주문하기</li>
</ol>
```

```text
1. 메뉴 고르기
2. 맵기 선택하기
3. 주문하기
```

- `<ul>`: 순서가 없는 목록
- `<ol>`: 순서가 있는 목록
- `<li>`: 목록의 항목






# 09 입력 태그

사용자에게 값을 입력받을 때 사용함

```html
<input
    type="text"
    placeholder="이름을 입력하세요."
>
```

## 자주 사용하는 `input` 타입

```html
<input type="text">
<input type="password">
<input type="email">
<input type="number">
<input type="checkbox">
<input type="radio">
```

| 타입 | 설명 |
|---|---|
| `text` | 일반 텍스트 입력 |
| `password` | 비밀번호 입력 |
| `email` | 이메일 입력 |
| `number` | 숫자 입력 |
| `checkbox` | 여러 항목 선택 |
| `radio` | 하나의 항목 선택 |






# 10 입력 양식

`<form>`은 사용자의 입력 내용을 하나의 양식으로 묶음

```html
<form>
    <label for="name">이름</label>

    <input
        id="name"
        type="text"
        placeholder="이름을 입력하세요."
    >

    <button type="submit">
        제출
    </button>
</form>
```

| 태그 | 설명 |
|---|---|
| `<form>` | 입력 양식을 묶음 |
| `<label>` | 입력창의 이름을 표시함 |
| `<input>` | 값을 입력받음 |
| `<button>` | 버튼을 생성함 |






# 11 선택 목록

`<select>`와 `<option>`으로 선택 목록을 만들 수 있음

```html
<label for="spicy">맵기 선택</label>

<select id="spicy">
    <option>순한맛</option>
    <option>보통맛</option>
    <option>매운맛</option>
</select>
```

여러 줄의 긴 글을 입력받을 때는 `<textarea>`를 사용함

```html
<textarea
    placeholder="요청사항을 입력하세요."
></textarea>
```






# 12 주석

주석은 브라우저 화면에 표시되지 않고 코드에 설명을 작성할 때 사용함

```html
<!-- 닭발 메뉴 영역 -->
<h2>닭발 메뉴</h2>
```

주석은 코드의 내용을 설명하거나 잠시 코드를 숨길 때 사용함






# 13 자주 사용하는 태그 정리

| 태그 | 역할 |
|---|---|
| `<h1>` ~ `<h6>` | 제목 |
| `<p>` | 문단 |
| `<div>` | 블록 영역 |
| `<span>` | 인라인 영역 |
| `<br>` | 줄바꿈 |
| `<hr>` | 구분선 |
| `<a>` | 링크 |
| `<img>` | 이미지 |
| `<ul>` | 순서 없는 목록 |
| `<ol>` | 순서 있는 목록 |
| `<li>` | 목록 항목 |
| `<form>` | 입력 양식 |
| `<input>` | 입력창 |
| `<button>` | 버튼 |
| `<select>` | 선택 목록 |
| `<textarea>` | 여러 줄 입력창 |






# 14 정리

- HTML 태그는 웹 페이지의 구조와 내용을 나타냄
- 제목은 `<h1>`부터 `<h6>`까지 사용함
- 문단은 `<p>`로 작성함
- `<div>`는 한 줄을 차지하고 `<span>`은 내용 영역만 차지함
- 링크는 `<a>`, 이미지는 `<img>`로 작성함
- 목록은 `<ul>`, `<ol>`, `<li>`를 사용함
- 사용자 입력은 `<form>`, `<input>`, `<button>`을 사용함
- 태그마다 역할이 다르므로 목적에 맞는 태그를 사용해야 함

> ⇒ HTML 태그는 제목, 문단, 링크, 이미지, 목록처럼 웹 페이지의 각 요소를 표현하는 기본 문법 🍀
