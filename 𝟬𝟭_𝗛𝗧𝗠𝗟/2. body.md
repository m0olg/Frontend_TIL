# 01 제목
* 꺽쇠에 h, 숫자 쓰고 제목 작성 숫자는 1부터 6까지 존재함 (h = heading 태그의 약자)
# 02 문단
* `<p>`로 작성, 제목보단 두껍지 않고 작음 (p = paragraph)

> 이거 말고도 태그가 진짜 많은데 다 외울 필요는 없고 실습하면서 외우면 됨

# 03 `<div>` 및 `<span>`
겉보기엔 별 차이 없어보이지만 개발자모드로 들어가면 \
* div는 한 줄을 차지해서 반드시 줄바꿈이 일어나고 (= BLOCK 요소)
* span은 딱 안에 컨텐츠(글자)영역만 차지함 (= INLINE 요소)
```html
<span>하치와레 불쌍해</span>
<span>우사기 돼지</span>
```
`= 하치와레 불쌍해 우사기 돼지` 인라인 요소이기 때문에 그냥 옆에 출력됨 \
그래서 span은 000"님" 같을 때 사용함 \
```html
<span>하치와레 <span>님</span></span>
```
