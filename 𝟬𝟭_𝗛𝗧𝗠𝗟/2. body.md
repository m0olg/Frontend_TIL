# 01 제목

`<h1>`부터 `<h6>`까지 사용해 제목을 작성함

```html
<h1>가장 큰 제목</h1>
<h2>두 번째 제목</h2>
<h3>세 번째 제목</h3>
```

숫자가 작을수록 중요도가 높고 글자가 크게 표시됨

- `<h1>`: 가장 중요한 제목
- `<h2>`: 큰 단락 제목
- `<h3>` ~ `<h6>`: 하위 제목




# 02 문단

`<p>`로 문단을 작성함

```html
<p>HTML은 웹 페이지의 구조를 만드는 언어입니다.</p>
```

제목보다 작고 일반적인 글자를 표시할 때 사용함

> HTML 태그는 정말 많지만 전부 외울 필요는 없고, 실습하면서 자주 사용하는 태그부터 익히면 됨




# 03 `<div>` 및 `<span>`

겉보기에는 비슷하지만 차이점이 있음

- `<div>`: 한 줄 전체를 차지하는 **블록 요소**
- `<span>`: 콘텐츠 영역만 차지하는 **인라인 요소**

```html
<div>하치와레 불쌍해</div>
<div>우사기 돼지</div>
```

```text
하치와레 불쌍해
우사기 돼지
```

`<div>`는 한 줄을 차지하기 때문에 자동으로 줄바꿈이 발생함

```html
<span>하치와레 불쌍해</span>
<span>우사기 돼지</span>
```

```text
하치와레 불쌍해 우사기 돼지
```

`<span>`은 글자 영역만 차지하기 때문에 옆으로 이어서 표시됨

특정 단어나 글자에만 의미를 주고 싶을 때 사용함

```html
<span>하치와레 <span>님</span></span>
```




# 04 링크

`<a>`로 다른 페이지나 사이트로 이동하는 링크를 작성함

```html
<a href="https://www.google.com">구글로 이동</a>
```

`href`에는 이동할 주소를 작성함

새 탭에서 열고 싶다면 `target`을 사용함

```html
<a
    href="https://www.google.com"
    target="_blank"
>
    구글 새 탭에서 열기
</a>
```




# 05 이미지

`<img>`로 이미지를 표시함

```html
<img
    src="chicken-feet.jpg"
    alt="닭발 사진"
>
```

| 속성 | 설명 |
|---|---|
| `src` | 이미지 파일의 경로 |
| `alt` | 이미지가 표시되지 않을 때 나타나는 설명 |

`<img>`는 닫는 태그가 없는 태그임

이미지 크기는 `width`와 `height`로 설정할 수 있음

```html
<img
    src="chicken-feet.jpg"
    alt="매운 닭발 사진"
    width="300"
>
```




# 06 목록

목록은 `<ul>`, `<ol>`, `<li>`를 사용해 작성함

## 순서가 없는 목록

```html
<ul>
    <li>무뼈 닭발</li>
    <li>주먹밥</li>
    <li>계란찜</li>
</ul>
```

```text
• 무뼈 닭발
• 주먹밥
• 계란찜
```

## 순서가 있는 목록

```html
<ol>
    <li>닭발 고르기</li>
    <li>맵기 선택하기</li>
    <li>주문하기</li>
</ol>
```

```text
1. 닭발 고르기
2. 맵기 선택하기
3. 주문하기
```

- `<ul>`: 순서가 없는 목록
- `<ol>`: 순서가 있는 목록
- `<li>`: 목록의 항목




# 07 입력 폼

사용자에게 정보를 입력받을 때 `<form>`과 입력 태그를 사용함

```html
<form>
    <label for="name">이름</label>
    <input
        id="name"
        type="text"
        placeholder="이름을 입력하세요."
    >

    <button type="submit">제출</button>
</form>
```

## 자주 사용하는 입력 타입

```html
<input type="text">
<input type="password">
<input type="email">
<input type="number">
<input type="checkbox">
<input type="radio">
```

| 태그 또는 속성 | 설명 |
|---|---|
| `<form>` | 입력 양식을 묶음 |
| `<label>` | 입력창의 이름을 표시함 |
| `<input>` | 사용자의 값을 입력받음 |
| `<button>` | 버튼을 생성함 |
| `placeholder` | 입력 전 안내 문구를 표시함 |

예를 들어 닭발 주문 옵션은 다음처럼 작성할 수 있음

```html
<label for="spicy">맵기 단계</label>
<select id="spicy">
    <option>순한맛</option>
    <option>보통맛</option>
    <option>매운맛</option>
</select>

<label>
    <input type="checkbox">
    주먹밥 추가
</label>
```
