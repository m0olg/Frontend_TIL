# 01 시작하는 방법
* java든 python이든 html이든 코드는 위에서 아래로 읽음
```html
<!DOCTYPE html>
<html>
    <head></head>
    <body></body>
</html>
```
<sub> 한 줄씩 해석해보자면
`<!DOCTYPE html>` : doctype은 document type의 약자임 \ 컴퓨터는 멍청하기 때문에 html 파일을 열기 위해서는 다운을 받아와야함 그때 맨 윗줄에 이 문서는 html 타입이다 라고 알려주는 것 (파일당 한 줄)

`<html>` : 이건 그냥 쉽게 젤 위에서 감싸는 태그라고 생각하면 됨 (그래서 항상 한 개가 꼭 있어야 함)

`<head>` : 웹사이트의 정보를 담고 있는 태그 (ex. 시간대 나라, 국가 등을 head 태그에 담아주면 됨)

`<body>` : 웹사이트의 내용을 담고 있는 태그, 실제로 보여지는 웹사이트를 구성함


# 02 `Tag`
HTML은 Tag로 이루어져 있음 \
Tag라는 건 HTML을 구성하는 기본 요소라 꺽쇠 <>로 이루어짐

### 꺽쇠의 종류
`<>` : 열린 태그 \
`/<>` : 닫힌 태그 \
이렇게 슬래시가 있냐 없냐에 따라 나뉘고 연게 있으면 항상 닫는 것도 있어야 함
